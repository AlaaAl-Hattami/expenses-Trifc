Expenses Tracker
Expenses Tracker is a smart and intuitive full-stack application designed to help users efficiently track, manage, and analyze their daily and monthly financial expenses. Built with simplicity and clarity in mind, this app allows users to log spending, categorize expenses, set budgets, and receive alerts when limits are exceeded — all in a clean and modern interface.

🔍 Key Features:
Add, edit, and delete expenses easily

Monthly summaries and visual insights

Category-based tracking for better budgeting

CSV export functionality

Budget limit warning system

Built with React, TailwindCSS, Node.js, and NestJS

💻 Technologies Used:
Frontend: React, TailwindCSS

Backend: Node.js, NestJS

Database: PostgreSQL

Additional Tools: CSV export, Budget limit notifications
